# תקציב הבית 🏠

אפליקציה אישית לניהול תקציב ביתי (PWA) – מותאמת לאנדרואיד, בעברית, עובדת גם ללא אינטרנט.

- **תוכנית העבודה וההתקדמות:** [PLAN.md](PLAN.md)
- **יומן גרסאות:** [CHANGELOG.md](CHANGELOG.md)

## התקנה על הטלפון (אנדרואיד)
1. ב-GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   בוחרים את הענף (branch) הרצוי ותיקייה `/ (root)` ושומרים.
2. אחרי דקה-שתיים האפליקציה תהיה זמינה בכתובת `https://<user>.github.io/<repo>/`.
3. פותחים את הכתובת ב-Chrome בטלפון → תפריט ⋮ → **"התקנת אפליקציה" / "הוספה למסך הבית"**.

> הנתונים נשמרים **רק בטלפון** (לא נשלחים לשום שרת). מומלץ לגבות מדי פעם דרך ⚙️ → "גיבוי לקובץ".

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html`, `css/styles.css` | ממשק |
| `js/app.js` | מסכים, טפסים ואירועים |
| `js/calc.js` | חישובים: חיובים לפי חודש, תשלומים, ממוצע יומי, צפי |
| `js/insights.js` | מנוע תובנות |
| `js/storage.js` | שמירה מקומית, גיבוי ושחזור |
| `sw.js`, `manifest.webmanifest` | התקנה ועבודה אופליין |

## פיתוח
```bash
npm test      # בדיקות יחידה (Node 18+)
npm start     # שרת מקומי בכתובת http://localhost:8080
```
