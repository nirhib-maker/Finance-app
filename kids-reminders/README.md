# תזכורות לבנות 📚🎒

אפליקציית אנדרואיד שקוראת את ההתראות של וואטסאפ **רק מהקבוצות שבחרת** (הגן של מילי, בתי הספר של רומי ולני),
מזהה את מה שחשוב, ומוסיפה ל-Google Calendar:

| סוג | דוגמה | מה קורה |
|---|---|---|
| 📝 מבחן | "ביום ג' מבחן בחשבון" | אירוע של יום שלם + תזכורת 3 ימים לפני (18:00) ובערב שלפני (20:00) |
| 🎒 להביא | "מחר להביא תחפושת" | אירוע ביום עצמו + תזכורת בערב שלפני ב-20:00 |
| 🎉 אירוע | "אסיפת הורים 12/11 בשעה 18:30" | אירוע בשעה המדויקת + תזכורת שעה לפני ובערב שלפני |
| ⚠️ שינוי | "ביום א' אין לימודים" | אירוע + תזכורת בערב שלפני |
| 💰 תשלום / ✍️ טופס | "להעביר 50 ש"ח עד 15/11" | אירוע ביום היעד |

בנוסף:
- **התראה על כל פריט חדש** – עם כפתור "בטל" (אם נוסף ליומן בטעות) או "הוסף ליומן" (אם בחרת לאשר ידנית).
- **סיכום ערב** (ברירת מחדל 20:00): מה כל אחת צריכה מחר, ומה מתקרב השבוע.
- **מסך סיכום** באפליקציה: כל הפריטים הקרובים לפי תאריך + ההודעות האחרונות מהקבוצות.
- **מצב חכם עם Claude (אופציונלי)**: הבנה מדויקת יותר של ההודעות + סיכום כתוב לכל ילדה.

## התקנה

1. בטלפון, פותחים את דף ה-Releases של המאגר ב-GitHub → **kids-reminders-latest** → מורידים את `kids-reminders.apk`.
   (או: Actions → kids-reminders (Android) → הריצה האחרונה → Artifacts.)
2. פותחים את הקובץ. אנדרואיד יבקש לאשר "התקנה ממקור לא ידוע" לדפדפן – מאשרים.
3. פותחים את האפליקציה → **הגדרות**:
   - **קריאת התראות** → "אישור" → מפעילים את "תזכורות לבנות". (באנדרואיד 13 ומעלה, אם האפשרות אפורה:
     הגדרות → אפליקציות → תזכורות לבנות → ⋮ למעלה → "התרת הגדרות מוגבלות", ואז שוב.)
   - **גישה ליומן** → אישור. נבחר אוטומטית היומן הראשי של חשבון ה-Google; אפשר לבחור יומן אחר
     (למשל יומן משפחתי משותף, כדי שגם בן/בת הזוג יראו).
   - **הצגת התראות** → אישור.
4. **קבוצות**: אחרי שמגיעה הודעה מכל קבוצה היא מופיעה ברשימה. לוחצים עליה ובוחרים מילי / רומי / לני.
   אפשר גם להוסיף קבוצה ידנית לפי השם המדויק שלה.
5. בדיקה: במסך **סיכום** → "🧪 בדיקה עם הודעה" → מדביקים הודעה אמיתית מהקבוצה ורואים מה זוהה.

### חשוב לדעת
- **קבוצה מושתקת (Mute) בוואטסאפ לא שולחת התראות**, ולכן האפליקציה לא תראה אותה. אם הקבוצות מציקות –
  במקום להשתיק, בוואטסאפ: פרטי הקבוצה → "התראות מותאמות אישית" → צליל "ללא", רטט כבוי, וחלון קופץ כבוי.
  ככה ההתראה עדיין נוצרת (בשקט) והאפליקציה קוראת אותה.
- אם הצ'אט פתוח על המסך כשמגיעה הודעה, וואטסאפ לא שולח התראה – ההודעה הזו לא תיקלט.
- הודעות שהגיעו לפני ההתקנה, או לפני שהקבוצה שויכה, לא נקראות.
- תמונות ו-PDF (למשל מערכת שעות או רשימת ציוד כקובץ) לא נקראים – רק הטקסט וכיתוב התמונה.
- זיהוי לפי מילות מפתח (בלי Claude) עלול לפספס או להוסיף פריט מיותר – בשביל זה יש כפתור "בטל" בהתראה.

## מצב חכם עם Claude (אופציונלי)

בלי Claude הכול רץ על המכשיר בלבד ושום הודעה לא יוצאת ממנו.
עם Claude, ההודעות **מהקבוצות שבחרת בלבד** נשלחות ל-API של Anthropic לניתוח.

1. יוצרים מפתח API ב-[console.anthropic.com](https://console.anthropic.com) (דורש אמצעי תשלום; לכמה עשרות הודעות ביום העלות זניחה).
2. באפליקציה → הגדרות → מפעילים "להשתמש ב-Claude", מדביקים את המפתח → "בדוק חיבור".

איך זה עובד: הודעות נאספות ונשלחות יחד כ-3 דקות אחרי ההודעה האחרונה (כדי לחסוך בקשות).
המודל ברירת המחדל הוא `claude-opus-5-5`, ואפשר לשנות אותו בהגדרות. אם המודל מסרב לבקשה, היא עוברת אוטומטית למודל חלופי
(server-side fallback). אם אין אינטרנט או שהבקשה נכשלת פעמיים, ההודעות מנותחות לפי מילות המפתח, כך שלא מפספסים כלום.
המפתח נשמר בהגדרות הפרטיות של האפליקציה ולא מגובה (allowBackup כבוי).

## עדכון גרסה בלי למחוק את האפליקציה (מומלץ)

כל בנייה ב-GitHub חותמת את ה-APK במפתח זמני אחר, ולכן כדי להתקין גרסה חדשה צריך קודם להסיר את הישנה
(ואז ההגדרות נמחקות). כדי לחתום תמיד באותו מפתח, פעם אחת במחשב:

```bash
keytool -genkeypair -v -keystore kids.jks -alias kids -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 kids.jks   # במק: base64 -i kids.jks
```

וב-GitHub: Settings → Secrets and variables → Actions → מוסיפים
`KIDS_KEYSTORE_BASE64` (הפלט של base64), `KIDS_KEYSTORE_PASSWORD`, `KIDS_KEY_ALIAS` (= kids), `KIDS_KEY_PASSWORD`.
את `kids.jks` שומרים במקום בטוח ולא מעלים למאגר.

## מבנה הקוד

| מודול | תוכן |
|---|---|
| `core/` | Kotlin רגיל (בלי אנדרואיד), עם בדיקות: `HebrewDateParser` (מחר / ביום ג' / 12.11 / ה-12 בנובמבר / בשעה 8:30), `RuleExtractor` (מילות מפתח), `ClaudeExtractor` (Claude עם פלט JSON מובנה), `DigestBuilder`, `WhatsAppTitle` |
| `app/` | `WhatsAppListener` (קריאת ההתראות), `Actions` (הודעה → פריטים → יומן), `CalendarHelper` (CalendarContract, מסתנכרן ל-Google Calendar), `Notifier`, `Work` (WorkManager: Claude + סיכום ערב), `Store` (JSON מקומי), `MainActivity` |

```bash
./gradlew :core:test :app:assembleDebug        # עם Android SDK
gradle -PcoreOnly=true :core:test              # בלי Android SDK – בדיקות הליבה בלבד
```
